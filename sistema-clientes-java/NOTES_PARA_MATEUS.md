# Antes de publicar

Este projeto foi preparado como uma base de portfólio. Antes de publicar, o Mateus deve abrir, executar, testar e entender as principais classes e métodos.

## Checklist

- [ ] Abrir no NetBeans
- [ ] Executar a aplicação
- [ ] Cadastrar um cliente fictício
- [ ] Listar clientes
- [ ] Buscar cliente
- [ ] Atualizar cliente
- [ ] Remover cliente
- [ ] Executar os testes do Maven
- [ ] Ler o README
- [ ] Fazer pelo menos algumas alterações próprias no código
- [ ] Publicar no GitHub

## Dados

Use somente dados fictícios durante os testes e nunca publique dados reais de clientes.
